================================================================================
  BƯỚC SETUP (MỘT LẦN — ~10 phút)
================================================================================

  1. Kết nối GitHub
     https://cursor.com/dashboard/integrations
     → Connect GitHub → đăng nhập dongjusports-cyber
     → Chọn repo: dongjusports-cyber/hrm (quyền read-write)

  2. Cloud Environment — BUILD (sau khi đã sửa environment.json)
     Mở:  https://cursor.com/dashboard/cloud-agents

     Lần đầu (chưa có môi trường):
       → Environments → New environment
       → Repo: dongjusports-cyber/hrm   Branch: main
       → Create / Build

     Đã có môi trường (sửa file xong, lỗi parse ports):
       → Tab Environments
       → Chọn môi trường DJ HRM (repo hrm)
       → Tab Builds → Rebuild / Build
       → Đợi đến khi Status = Ready / Success
         (cài Postgres test + Python + npm — khoảng 5–15 phút)

     Thành công khi thấy:
       • Không còn "Failed to parse environment.json"
       • Log có dòng: [install] Xong
       • Agents có thể chat / chạy test

     Nếu Build fail: copy dòng lỗi đỏ, hỏi AI trên máy .123.

  3. Default settings
     • Default repository: dongjusports-cyber/hrm
     • Base branch: main
     • Branch prefix: cursor/  (giữ như Settings → Git & PRs)

  4. (Tùy chọn) Automation tối 22:00
     https://cursor.com/automations/new
     → Scheduled hàng ngày
     → Repo hrm, branch main
     → Dán prompt từ file: PROMPT-TOI-CLOUD.txt
