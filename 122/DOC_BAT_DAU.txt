================================================================================
  THƯ MỤC 122 — COPY USB → MÁY NHÀ MÁY (.122)
  Tạo trên máy .123:  C:\DATA\HRM\dj-hrm\dj-hrm\122\
================================================================================

  Mục đích: bạn copy cả folder "122" vào USB, dán sang máy .122, chạy vài file .bat
  — không cần share mạng .123 ↔ .122.

--------------------------------------------------------------------------------
  BƯỚC 1 — USB
--------------------------------------------------------------------------------

  Copy folder   122\   (toàn bộ)  →  USB

  Trên máy .122: dán vào Desktop hoặc  D:\122\  (tùy bạn)

--------------------------------------------------------------------------------
  BƯỚC 2 — TRÊN MÁY .122 (lần đầu hoặc đổi cấu hình)
--------------------------------------------------------------------------------

  0.  00-TAO-PYTHON-LOCAL.bat       → BẮT BUỘC nếu báo "No Python at ... Dongju Spots Pro"
                                      (xóa .venv copy từ .123, tạo Python mới; GIỮ .env)
  1.  01-KIEM-TRA-ODBC.bat          → xem máy có ODBC 17 hay 18 (đọc HUONG-DAN-ODBC.txt)
  2.  02-GHEP-ENV.bat               → dán file .env vào D:\dj-hrm\apps\agent\
  3.  03-CHAY-AGENT-NEN.bat         → chạy tay (cửa sổ CMD, Ctrl+C để dừng)
  4.  04-CAI-TU-CHAY-KHI-MO-MAY.bat → CÀI MỘT LẦN (chuột phải / Run as administrator)
  5.  05-TAT-TU-CHAY.bat            → gỡ tự-chạy (nếu cần)

  Sau bước 4: không cần bấm 03 mỗi sáng. Tắt máy thì agent tự dừng.
  Agent tự đẩy công về VPS mỗi 2 phút — không cần bấm Đồng bộ trên web.
  Log ngầm: D:\dj-hrm\apps\agent\agent.log

  Lưu ý: agent dùng tài khoản Windows để đọc SQL Mitapro, nên chạy khi
  user đã đăng nhập (máy nhà máy thường tự đăng nhập). Không chạy kiểu
  SERVICE/SYSTEM lúc boot — SQL sẽ không đọc được.

  Agent code đã có sẵn tại:  D:\dj-hrm\apps\agent\
  (nếu thiếu code → xem mục "Cập nhật code agent" bên dưới)

--------------------------------------------------------------------------------
  BƯỚC 3 — TRÊN MÁY .123 (bạn)
--------------------------------------------------------------------------------

  Portal → Chấm công: lưới tự cập nhật (agent đẩy mỗi 2 phút).
  Nút Đồng bộ chỉ dùng khi muốn kéo lại cả tháng / khoảng ngày cũ.

--------------------------------------------------------------------------------
  CẬP NHẬT CODE AGENT (khi cần bản mới từ .123)
--------------------------------------------------------------------------------

  Copy từ .123 sang USB (ngoài folder 122):

    C:\DATA\HRM\dj-hrm\dj-hrm\apps\agent\

  Dán đè lên .122:

    D:\dj-hrm\apps\agent\

  KHÔNG xóa file .env trên .122 (hoặc chạy lại 02-GHEP-ENV.bat sau khi copy).

  Bỏ qua folder:  .venv   __pycache__   .pytest_cache
  (copy .venv từ .123 sẽ lỗi "No Python at ... Dongju Spots Pro")

  Sau đó trên .122 chạy:  00-TAO-PYTHON-LOCAL.bat  rồi  04-CAI-TU-CHAY-KHI-MO-MAY.bat

--------------------------------------------------------------------------------
  PRODUCTION (VPS) — sau này
--------------------------------------------------------------------------------

  Dùng file:  env-VPS.txt  → chạy 02-GHEP-ENV.bat  (chọn VPS khi hỏi)
  hoặc sửa tay .env:  DJ_API_BASE_URL=https://hrm.dongju-v.com
